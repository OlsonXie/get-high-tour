# Get High Tour

Utkast till en app för toppturer i Lyngen och Tromsø (11–21 mars 2027).

**Live:** https://olsonxie.github.io/get-high-tour/

- Föreslagna rutter med reliefbilder och "passar oss"-bedömning
- Interaktiv 3D-karta (satellit, Kartverket topo, NVE bratthet)
- Lavinläge från Varsom, väder från Open-Meteo
- GPX-uppladdning och betyg (sparas än så länge lokalt i webbläsaren)

Beslutsstöd, inte beslut – gör alltid egen bedömning på plats.
